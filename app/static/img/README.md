# Static images

- `hop-fallback.svg` — bundled fallback when no brewery logo is available.
- `palindrome-logo.png` — your Palindrome Brewing Co wordmark, shown in the display header. **Drop your file here**; the display gracefully hides the slot if it's missing.

Recommended formats:
- PNG with transparent background, ~600px wide, for the wordmark.
- Square or round PNG/SVG, ~512px, for any logo upload via the admin Settings page.
